# v5.59 — Education / Employment / Income Were Never Wired Up

**Date:** 2026-10-22
**Live:** https://qcm8a40uzgrkv.space.mcode.cn

## How this was found

Monte-Carlo over the real `DECISIONS[].chance()` functions for 300 synthetic lives showed that
**10 of the 16 "big" decision events never fired in an entire lifetime**. Tracing the gates
exposed three pre-existing defects that made most of the simulation inert.

> **Corrected by v5.60.** Two claims in this file were wrong, both caused by my Monte-Carlo
> harness building family state the real app never produces. See
> `v5.60-parents-alive-gate-fix.md`:
> - "1 never-firing event" was actually **3** — `de_parents_care` and `de_inheritance` were
>   also permanently dead (they read `p.alive`, which `generateFamily` never sets).
> - "193 i18n keys" was actually **263** (`de.` 173 + `sm.` 83 + `dec.` 7).

## Defect 1 — `education` was a dead value

`stats.education` was initialised to `0`, and the only write anywhere in the file was
`life.stats.education = 1` (age 15). Therefore:

- `education >= 2` was **never true** → `employment` was never set to `'employed'`
- `education === 4` was never true → nobody ever graduated or attended university
- `education >= 2` was never true → `knowledge` never grew

The UI label (`educLabels[Math.min(education + 1, 5)]`) therefore read **學齡前（未上學）for
every person, always**.

**Fix:** draw an attainment ceiling at birth from the country's real statistics, then let
`education` climb toward it as the person ages.

```js
function rollEducation(c) {
  const base = Number.isFinite(c?.eys) ? c.eys : 12;
  const eys = base + (Math.random() * 6 - 3);   // ±3 yrs individual variance
  let lvl;
  if (eys < 6.5) lvl = 0; else if (eys < 9.5) lvl = 1;
  else if (eys < 12) lvl = 2; else if (eys < 15) lvl = 3; else lvl = 3;
  if (eys >= 15) {
    const ter = Number.isFinite(c?.ter) ? c.ter : 30;
    if (Math.random() * 100 < ter) lvl = 4;
  }
  return lvl;
}
```

`eys` = expected years of schooling, `ter` = tertiary enrolment rate. Stored as `life.eduTarget`.

Milestones now progress toward it (age 6 primary → 12 lower secondary → possible 15 dropout
→ 18 high school or work → 22 university → 24-27 enters the workforce).

## Defect 2 — `employment === 'employed'` was never true

`employment` was only ever assigned `'none'` (init), `'university'` (age 22), `'retired'`
(age 60) and `'family_biz'` (a decision effect). The age-18 branch pushed a "開始工作" event
but **forgot to set the flag**.

Consequences: income never accumulated, the job label never showed 在職, and five decision
events gated on `employment === 'employed'` were dead code.

**Fix:** set `employment = 'employed'` when entering the workforce, `'seeking'` on graduation,
and convert `'university' → 'employed'` between ages 24–27.

## Defect 3 — `annualIncome` was always 0

Initialised to `0`, never assigned. So even with employment fixed, `netAssets` never grew.

**Fix:** base it on the country's `ppp`, scaled by education and income quartile, with the
saving rate also rising by quartile (high earners save a larger share):

```js
const gross   = ppp * 0.9 * eduMult * qMult;   // 0.9 matches the original's incomeAt()
const saveRate = [0.15, 0.22, 0.28, 0.40][quartile - 1];
netAssets += gross * saveRate;
```

An earlier attempt subtracted a fixed `ppp * 0.75` living cost. That was rejected: it doesn't
scale with the person's own income, so low-education lives collapsed to large negative net
worths (p10 = −$257k, median = $0).

## Defect 4 — happiness could only move one way

`happiness` was changed *only* by explicit player choices, starting at 70. Reaching the
`de_mental_health` gate of `< 40` would require a net −30 swing, but a life only contains
~17 decisions. The event was unreachable.

**Fix:** happiness now mean-reverts toward a baseline set by circumstances (health, social,
employment, debt), so a rough patch is genuinely reachable:

```js
baseline = 45 + (health-60)*0.35 + (social-60)*0.12
         + (employed ? 8 : university ? 5 : retired ? 3 : -2)
         + (netAssets < 0 ? -8 : 0);
happiness += (baseline - happiness) * 0.06;
```

Gate widened `happiness < 40` → `(happiness < 55 || social < 35)`.
