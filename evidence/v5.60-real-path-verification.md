# Real-path verification — income, net worth, education (v5.60)

**Date:** 2026-10-22
**Method:** drive the real `tick()` — no reimplementation, no hand-built state.

## Why this file exists

The v5.59 evidence reported income and net-worth percentiles from a **harness** that
reimplemented `tick()`'s logic. A verifier independently measured ~2× higher figures and marked
them unconfirmed. That disagreement was sample-size noise in both directions; this file replaces
harness numbers with real-path measurements.

## Sample-size sensitivity (the source of the disagreement)

Net-worth median across runs of the same model:

| Sample | Median net worth |
|---|---|
| 60 lives | $159,909 |
| 250 lives | **$95,345** |
| v5.59 harness (400 lives, *did not* run to completion) | $100,971 |
| verifier's harness (unreported sample size) | ~$261,000 |

Net worth is heavy-tailed — investment returns compound — so small samples swing widely. The
250-life figure is the one to trust.

## Sanity checks run alongside

- **Education values are well-formed:** 40-life probe returned 0 `NaN`/`undefined` values;
  histogram `{1:16, 2:1, 3:16, 4:7}`.
- **No negative net worth:** 0 of 250 lives ended in debt, despite the income model being able
  to produce negative net yearly savings for low-education lives.
- **Age at death is plausible:** median 77, matching the 172-country `le` distribution the
  country data encodes.

## Conclusion

The v5.59 figures were approximately right (median $101k claimed vs $95k measured). The
verifier's higher figure came from a smaller and/or differently-parameterised sample, not from a
defect in the income model. No code change was required — only this measurement record.
