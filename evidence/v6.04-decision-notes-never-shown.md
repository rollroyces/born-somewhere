# v6.04 — 玩家在決定裡寫下的話，寫完就再也看不見

## 量到的缺陷

訃聞上的「✦ 你做過的決定」面板（v5.78 加的）列出每一個選擇：

```
10 🐷 存進小豬存錢筒
18 📱 換新的
22 🍻 約朋友出去
27 🥂 去一趟
31 🍳 試著做一道新菜
35 🧘 開始戒菸戒酒、固定運動
```

而第 35 歲那個決定，**玩家當初在輸入欄寫了「當時真的很怕」**。
這句話沒有出現在面板裡，也沒有出現在任何地方。

## 根因：note 被存下來，但全檔案沒有任何地方讀它

作答當下確實有存：

```js
// showDecision() 第 155–160 行
const noteText = hasNote ? (note.value || '').trim() : '';
STATE.life.decisions.push({ id, age, key: k, label, icon, note: noteText, lang: LANG });
```

但 `renderEndDecisionsInner()` 只渲染三個欄位：

```js
return `<div class="ed-row">
  <span class="ed-age">${r.age ?? '?'}</span>
  <span class="ed-icon">${escapeHtml(icon)}</span>
  <span class="ed-text">${escapeHtml(label)}</span>
</div>`;                      // ← 沒有 r.note
```

掃過全檔案所有 `.note` 的讀取，命中到的全是**家族節點**的
`p.note`（`adoptive` / `foster` 標記），與決策紀錄無關。
`grep -n "life.decisions"` 也確認沒有其他地方消費這個欄位。

也就是說：note 確實被持久化了（匯出／匯入都會帶著），
但**玩家自己永遠不會再看到自己寫的東西**。

目前有 5 個決策開了 `hasNote: true`（`app.js` 第 262、367、448、480、637 行），
也就是說至少 5 種決定在邀請玩家寫字，寫完即丟。

## 修法

在決定列後面多出一段斜體的引文，並濾掉系統代填的兩種值：

```js
const noteText = (r.note || '').trim();
const showNote = noteText && noteText !== '（自動抉擇）' && noteText !== '（隱蔽）';
...
${showNote ? `<span class="ed-note">「${escapeHtml(noteText)}」</span>` : ''}
```

```css
/* v6.04：玩家在決策裡自己寫的一句話 */
.ed-note { color: var(--ink-3); font-size: 12px; font-style: italic; }
```

`（自動抉擇）` 是 autoDecide 模式代填的、`（隱蔽）` 是跳過時代填的
（`savePauseQuote` 與 autoDecide 分支），都不是玩家寫的，不該顯示。

## 驗證

實際跑一段人生、在第 35 歲的決定寫下「其實我想回家」，訃聞面板：

```
35 🧘 開始戒菸戒酒、固定運動 「其實我想回家」
```

邊界情況逐一測試（直接餵 `renderEndDecisionsInner`）：

| 輸入的 note | 顯示 |
|---|---|
| `我當時很怕` | ✅ `「我當時很怕」` |
| `''`（空白） | 不顯示 |
| `（自動抉擇）` | 不顯示（系統代填） |
| `（隱蔽）` | 不顯示（系統代填） |
| `<img src=x onerror=alert(1)>` | ✅ 逃逸成文字，**注入的 `<img>` 標籤數 = 0** |
| 欄位不存在（v6.04 以前的舊紀錄） | ✅ 正常渲染，不會拋 |

## 附帶說明

這個缺陷是「功能存在但輸出被丟掉」——和 v5.96（證書底紋塞進 canvas）
同一類：程式寫了、資料也存了，但玩家看不到。

是因為去讀**匯出後的實際內容**才發現的：測試「決策備註有沒有存進去」
時確認存了，再去看訃聞面板，才發現沒顯示。

## 已知限制

- 備註只顯示在訃聞的決定清單裡，沒有出現在書架的紀錄詳情視窗、分享圖或
  人生故事（`getLifeStory` 只讀 `life.quotes`）。要一致地呈現應該三處都放，
  但那牽涉匯出版面（分享圖是固定 800×520 的 SVG，多行文字要重排），
  這次先修最明顯的那一處。
- 舊紀錄裡已經寫過的 note 會從這版開始全部顯示出來 ——
  等於把先前藏起來的內容還給玩家，是好事，但也代表書架裡存久了的紀錄
  會突然多出一行字。
