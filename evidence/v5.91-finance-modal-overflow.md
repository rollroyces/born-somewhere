# v5.91 — 財務視窗在手機上把「你有多少存款」推出畫面

## 量到的缺陷

360 × 640（常見手機尺寸）打開財務視窗：

```
card 高度 1140px   top = −250px   bottom = 890px   viewport 高 640px
```

視窗比螢幕高出 500px，而 `#financeModal` 是 `position: fixed`、`overflow: visible`，
`.modal-card` 當時**沒有任何高度上限**，卡片本身也不可捲動（`scrollTop` 寫 200 仍然是 0）。

結果是超出上緣的 250px 直接消失、而且捲不到。被切掉的正好是：

```
modal-q     「積蓄：NT$60,000」        ← 做這個決定最重要的資訊
modal-help  「選一項會影響淨資產與狀態。」
```

也就是說：**在 360px 寬的手機上，玩家看得見六個按鈕和上面的金額，卻看不到自己現在有多少錢。**
選項本身在 y=92～464，完整可見，所以這個 bug 不容易被發現 —— 畫面看起來「有內容」，
只是少了最上面那一塊。

其他視窗都沒事（同一個 360 × 640 下量測）：

| 視窗 | 高度 | 是否溢出 |
|---|---|---|
| pause | 309 | 否 |
| feedback | 377 | 否 |
| birthCert | 213 | 否 |
| decisionModal（實測 5 次，最大 4 選項） | 460 | 否 |
| **financeModal** | **1140** | **是** |

## 修法

`.modal-card` 加上高度上限並讓卡片自己捲：

```css
max-height: calc(100vh - 48px);
overflow-y: auto;
-webkit-overflow-scrolling: touch;
```

`-48px` 是扣掉 `.modal` 原本的 `padding: 24px`，讓視窗維持上下各留 24px 邊界。

## 修之後（同一個 360 × 640）

| | 修之前 | 修之後 |
|---|---|---|
| finance 高度 | 1140 | **592**（上限 592 = 640 − 48） |
| top | −250 | **24** |
| bottom | 890 | **616** |
| 內容被推出畫面 | 標題 + 說明 | **無** |
| 可捲動 | 否 | 是 |

其他視窗完全不受影響（高度都沒到上限，所以 `max-height` 不生效）：
pause 309、feedback 377、birthCert 213，數字與修之前一致。

桌面 1280 × 900：財務視窗 841px 本來就放得下，修之後一樣 841px、不捲動、標題可見。

## 為什麼這樣改是安全的

- `max-height` 只在「視窗裝不下」時才生效，量測到的其他四個視窗高度都遠低於上限，數字未變
- `overflow-y: auto` 在內容沒有溢出時不會產生捲軸，版面不動
- 桌機與行動版都用同一條規則，不需 media query 分岔

## 順帶確認

同一輪也量了決策視窗（v5.55 新增的那個核心功能）在 360 × 640 的表現：
實測 5 次、含 4 選項那次，卡片最高 460px、top 90、bottom 550，**沒有溢出也沒有橫向捲動**。
所以這次唯一需要動的是財務視窗。

## 驗證方式

```js
// 360x640（emulate viewport），逐一開啟視窗後量測
const card = modal.querySelector('.modal-card');
card.getBoundingClientRect();          // top / bottom / height
[...card.children].filter(c => c.getBoundingClientRect().bottom <= 0);  // 被推出畫面的子元素
card.scrollHeight > card.clientHeight + 2;                              // 是否需要捲
```

### 已知限制

- 只保證「內容不會消失、可以捲到」。財務視窗在 360 × 640 下仍然要捲 550px 才看得到
  底下的說明文字，那段是操作說明不是選項，捲不見得是問題；但如果之後再調高
  `.fin-grid` 的選項數量，應該考慮把說明文字收進可摺疊區塊。
- `.modal-card` 現在對所有視窗都生效。若之後新增內部自己捲動的視窗（例如樹狀圖），
  記得檢查是否會變成雙層捲動。
