# v6.07 — 高收入國家的宗教，100% 都是「無信仰」

## 量到的缺陷

對台灣抽 300 次 `pickReligion()`：

```
TWN: 無信仰 100%
```

對以色列抽 300 次：

```
ISR: 無信仰 100%
```

而 `data/countries.json` 裡明明寫著：

```
TWN: F44,B21,N14,C6,O15     ← 44% 佛教
ISR: J74,M18,C2,O6          ← 74% 猶太教
```

## 根因一：`region` 欄位是混用的，而宗教表沒有 `hi`

`countries.json` 的 `region` 欄位**同時放了兩種東西**：

| region 值 | 意義 | 國家數 |
|---|---|---|
| `sa` `mena` `ssa` `lac` `eap` `eca` | 地理區 | 134 |
| **`hi`** | **收入級距「高收入」** | **38** |

而 `pickReligion()` 的地區表只有 6 個地理區的 key，**沒有 `hi`**：

```js
const m = isEn ? mapEn : mapZh;
return pick(m[r] || (isEn ? ['Non-religious'] : ['無信仰']));
//                     ↑ 'hi' 落到這裡 → 永遠是「無信仰」
```

受影響的 38 國包括：**美國、日本、德國、英國、法國、以色列、台灣、韓國、
新加坡、澳洲、紐西蘭、加拿大…** — 也就是說**全高收入國家出生的人生，
宗教 100% 都被記成「無信仰」**，而這些國家的真實宗教資料都在檔案裡躺著。

（`pixelPortraitSVG()` 的膚色表裡**有** `hi`，所以程式碼是知道這個值的，
只是宗教與其他地方沒跟上。）

## 修法

### 1. `pickReligion()` 改用該國的 `c.rel`

```js
const parts = String(rel).split(',').map(s => ({ name: relMap[s[0]], pct: Number(s.slice(1)) }))
                     .filter(x => x.name && x.pct > 0);
// 依百分比加權抽；沒有 rel 時才退回原本的地區表
```

字母表之後仍保留原本的地區表當退路 —— 防禦性設計，即使資料哪天缺值也不會整個壞掉。

### 2. 順帶修掉 `pickParentJob()` 的死碼與固定骰子

同一個 `region` 混用問題的鄰居。`pickParentJob()` 裡有：

```js
const r = c.region || 'eap';    // ← 算了，從來沒用過
...
const isRural = Math.random() < 0.55;   // ← 固定 55%，每個國家都一樣
```

於是日本（92% 都市）和衣索比亞（23% 都市）的家長職業池長得一樣。
改成用該國真正的都市化率 `c.urb`：

```js
const isRural = Math.random() * 100 >= (c.urb ?? 55);
```

## 回歸測試

172 國各跑一段人生到自然死亡：**0 個未捕捉錯誤**。
全球宗教分布變成 8 種（修之前是 13 個拼錯的標籤）：

```
基督宗教 82 · 伊斯蘭 49 · 無信仰 20 · 印度教 6 · 民間信仰 6 · 佛教 5 · 其他 3 · 猶太教 1
```

（每國只抽一段人生，所以這是粗略的世界樣貌，但型態合理。）

## 這個缺陷為什麼會藏這麼久

和 v6.06 的自殺率同一個家族，但更隱蔽：

1. **看起來有實作** —— `pickReligion()` 是一個完整的函式，有地區表、有中英文兩版
2. **有資料** —— `c.rel` 172 國都有，格式乾淨、總和都是 100
3. **部分正確** —— 地區表對 134 個開發中國家確實有效
4. **錯的是「沒想到有這類」** —— 38 個最發達、最常被拿來示範的國家全部落在 fallback

是因為做 v6.06 收尾時順手問了一句「還有哪些欄位沒被讀」才找到的：
172 個欄位裡只剩 `cs`（只有台灣有值）和 `rel` 沒被任何程式碼引用。

**建議保留這個檢查：把 countries.json 的欄位和 app.js 的引用逐一對照。**
成本是幾秒鐘，抓到的卻是這種量級的錯誤。

## 已知限制

- 字母對照表是反推出來的（用各國實況比對），原始資料沒有附 schema。
  已用 9 個已知國家驗證過，但若之後新增字母需要同步更新 `REL_ZH` / `REL_EN`。
  沒有對應字母的會被 `filter` 掉，安全但會靜默遺漏。
- 原始分布把「基督宗教」合併成一個 C，沒有拆天主教／新教。
  修之前的地區表有分（`基督新教` / `天主教` / `東正教`），但那是地區平均值不是國別實況。
  採用資料的合併版本，因為它才是該國的真實比例。
- 舊存檔裡已經記成「無信仰」的宗教不會被回溯修正 —— 那些人生已經結束並存在書架了。
