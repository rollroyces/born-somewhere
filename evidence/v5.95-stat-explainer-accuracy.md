# v5.95 — 「狀態代表什麼」面板有兩行在說謊

## 缺陷

面板（`#stateInfoPanel`，ℹ️ 按鈕）用硬編碼的中英雙語字串說明每個統計量怎麼動。
拿每一行回去對程式碼，**人際**與**幸福**兩行都已經和實作不符。

### 人際：原文只描述被動來源，完全沒提到玩家的選擇

```
舊：60 + 伴侶（已婚 +10）+ 每位子女（+4）+ 工作年資（+2）。
```

逐項核對 `app.js`：

| 面板宣稱 | 程式碼裡實際有的 |
|---|---|
| 已婚 +10 | **沒有**任何「已婚 +10」 |
| 每位子女 +4 | **沒有**；+4 是「自動社交支出」（有資產時每年扣 2% 資產換 +4 人際，`app.js:2196`） |
| 工作年資 +2 | **沒有**；+2 是「戀愛／結婚／度假」事件的加成（`app.js:2494`） |

而真正主導這個數字的是**玩家的選擇** —— 20 個決策選項，範圍 −3 到 +8：

```
搬家到外地        −3      招待朋友        +4
彩金分給親友      +5      親戚接回家住    +4
買房子            +1      借錢給親戚      +6
只幫忙不拿錢      +3      遺產平分        +8
拜訪老友          +5      抽籤分喜訊      +5
只打電話不拜訪    −2      …
```

面板一個字都沒提。這直接誤導 —— 玩家讀完會以為人際關係是自動的、
選項無關緊要，而實測選擇落差是 **12 分**（永遠選第一個 77、最後一個 65）。
v5.92 量測時我一度誤判 `social` 是死值，就是被這種說明帶偏的。

### 幸福：原文停留在重構之前

```
舊：70 + 隨機事件。結婚生子 +10、生病 −15、養生焦點 +3。
```

但 v5.59 起幸福已經不是「70 + 事件」，而是每年往一個計算出來的基準回歸：

```js
const baseline = 45
  + (st.health - 60) * 0.35
  + (st.social - 60) * 0.12
  + (st.employment === 'employed' ? 8 : st.employment === 'university' ? 5
                                 : st.employment === 'retired' ? 3 : -2)
  + (st.netAssets < 0 ? -8 : 0);
st.happiness += (baseline - st.happiness) * 0.018;   // v5.86：6% → 1.8%
```

「70」這個數字從此不存在。面板描述的是一個已經被移除的模型。

## 修法

兩行都改成描述**實際模型**，包含玩家真正能控制的部分。
改完逐項寫腳本比對程式碼，9 個斷言全中：

```
OK  baseline 45            OK  employed +8        OK  reversion 0.018
OK  health x0.35           OK  university +5
OK  social x0.12           OK  unemployed -2
OK  retired +3             OK  debt -8
```

人際列同時補上「主要由你的選擇推動」以及選擇的實際區間（+1～+8 / −1～−3），
與 v5.92 量到的 12 分落差一致。幸福列則明講 1.8% 的回歸機制 ——
因為那正是「為什麼一個好選擇可以維持很多年」的原因，也是 v5.86 調慢回歸的用意。

## 順帶修掉

- `index.html` 補上 `<meta name="mobile-web-app-capable" content="yes">`。
  這是瀏覽器 console 唯一的一則警告（`apple-mobile-web-app-capable` 已棄用），
  補上後 console 完全乾淨，也讓「加入主畫面」在 Android Chrome 上走正確的路徑。

## 沒有動的

- **知識**那行是對的（「學歷 + 人生經歷。每年自我進修 +3、升上國中 +0.5」）：
  `focus==='study'` 給 +3、`education>=2` 後每年 +0.5，都與程式碼一致，沒碰。
- **健康**那行是 v5.90 剛改過的，已經對齊。

## 已知限制

- 面板的中英文是硬編碼字串（沿用這個面板一直以來的寫法），所以只有中英兩版，
  其他七種語言看到的是中文。這與面板既有行為一致，不是這次引入的；
  要補齊得把這些字串搬進 `data/i18n.json`，是另一件獨立的工。
