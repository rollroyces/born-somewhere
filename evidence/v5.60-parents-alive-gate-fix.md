# v5.60 — Two Permanently Dead Decision Gates (+ claim corrections)

**Date:** 2026-10-22

This file supersedes two claims made in `v5.59-education-employment-income-fix.md`.
Both errors came from the same root cause: **my Monte-Carlo harness constructed family state
that the real application never produces.**

## Claim correction 1 — "never-firing dropped 10→1" was wrong at the time

I reported 1 remaining never-firing event. It was **3**.

The harness built parents as `{ alive: true }`. The real `generateFamily()` never sets that
flag, so the two gates testing it were permanently false. Re-measuring with the family built
exactly as `generateFamily` builds it gives **3** never-firing events on the v5.59 code:

| Event | v5.59 (faithful harness) |
|---|---|
| `de_conscription` | never (correct — 6 of 172 countries) |
| `de_parents_care` | **never (bug)** |
| `de_inheritance` | **never (bug)** |

## The defect

`generateFamily()` (`app.js:1436-1451`) writes parent records with only `birth` and `death`
year objects. It **never sets `alive`**. Two decision gates read that flag:

```js
// de_parents_care  (was app.js:243)
life.family.parents.some(p => p.alive)
// de_inheritance   (was app.js:484)
life.family.parents.some(p => p.alive)
```

`p.alive` is `undefined` for every parent, so `.some()` is always `false` and both events were
dead code regardless of age or probability.

## Fix

Derive liveness from the year data the family generator *does* produce, instead of reading a
flag that is never written:

```js
function isAliveAt(person, year) {
  if (!person) return false;
  const b = person.birth?.year;
  if (b == null || b > year) return false;
  const d = person.death?.year;
  return d == null || d > year;
}
function anyParentAlive(life) {
  if (!life?.family?.parents) return false;
  const year = (life.year || 0) + (life.yearOffset || 0);
  return life.family.parents.some(p => isAliveAt(p, year));
}
```

Both gates now call `anyParentAlive(life)`.

### Result (400 lives, family built faithfully — no `alive` flag)

| Event | Before | After | Window |
|---|---|---|---|
| `de_parents_care` | never | **0.16 / life** | 45–74 |
| `de_inheritance` | never | **0.20 / life** | 40–76 |
| `de_conscription` | never | never | — |

Decisions per life: mean 16.4, median 16, range 10–21.

`de_conscription` remaining at zero is correct by design, not a defect: conscription exists in
6 of 172 countries and the gate additionally requires male + age 18–25.
